## #366 implications for this project

- Summer snow in the Falklands was fixed.
- An Argentina mast flag was added, improving visual reflagging options.
- The SS-1C Scud-B provides a native strategic missile/TEL object candidate.
- N22/Searchmaster variants expand regional light-aircraft/MPA options.
- Tanker substitutions must be revisited because KC-135 and Tu-16N placeholders were removed and KC-10 was added.
- Sturgeon dates, Los Angeles performance/load, refueling, ship loadouts, sensors, and submarine endurance changed.
- Formula-134 costs must not drive the campaign economy.
- Dynamic enemy theater generation is now available but is a design choice, not an automatic recommendation.
- Date-based loadout progression may simplify staged escalation.

No production mission or campaign decision is changed merely because a new engine feature exists. Each feature must earn its place through the project design and runtime validation.
